## Key Features

### Core Features (for all users)
- **Income and Expense Tracking:** Easily record and categorize all financial transactions.
- **Budget Creation and Monitoring:** Set monthly budgets and monitor spending to avoid overspending.
- **Financial Reporting and Analysis:** Visual dashboards and reports to help users understand their financial health.
- **User Authentication:** Secure login and registration system supporting individual and business users.

### Business-Specific Features
- **Invoicing:** Generate, send, and manage invoices for clients.
- **Payroll Basics:** Simple employee payment tracking functionality (planned for future versions).

### Individual User Features
- **Personal Budgeting:** Tools tailored for managing personal finances.
- **Savings Goals:** Set and track progress toward specific savings objectives.

## Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **APIs:** RESTful endpoints for transaction and budget management  

This choice of technologies ensures wide compatibility, easy deployment on common hosting platforms, and maintainability.

## How to Run

1. Import the provided SQL schema (`sql/init.sql`) into your MySQL server.
2. Configure database connection in `api/db.php`.
3. Deploy the PHP files and assets on a web server with PHP and MySQL support.
4. Open `login.html` in your browser to start using the app.
